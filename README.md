## 🧠 How to Use This Repo

This repo is built for **daily problem solving, pattern recognition, and fast revision**.  
Here’s how you can **utilize it effectively**:

| 📌 Goal                        | 🔍 What to Use                                                |
|-------------------------------|---------------------------------------------------------------|
| Solve daily problems          | Go to [`problems/`](./problems/) → Pick difficulty → Solve inside folder |
| Track your progress           | Use [`trackers/README.md`](./trackers/README.md) + [`LCrev.xlsx`](./trackers/LCrev.xlsx) |
| Review pattern-wise logic     | Read concise strategy notes inside [`patterns/`](./patterns/) |
| Reuse core code structures    | Use ready-made templates from [`snippets/`](./snippets/)     |
| Revise or cheat during mock   | Use tactical PDFs in [`cheatsheets/`](./cheatsheets/) (soon) |
| Log key takeaways             | See [`notes_log.md`](./trackers/notes_log.md)                |

> ⚙️ Master by solving, reviewing, and mapping every problem to a known pattern.
